Pathfinding Visualizer

An interactive visualization tool for pathfinding algorithms.

Algorithms:

  • A* (A-Star) — Heuristic-based, optimal pathfinding using f(n) = g(n) + h(n)
  • Dijkstra's — Guarantees shortest path without heuristics
  • BFS — Level-order traversal, shortest path in unweighted graphs
  • DFS — Stack-based exploration, does not guarantee shortest path
